# Repository Skills

Repository-local agent skills live here, one directory per skill with a `SKILL.md` package.

Common, cross-repository skills belong in the SDKWork skills distribution, not here. Add a local skill only when it captures repository-specific execution knowledge that cannot be expressed by a global standard or local spec.

Follow `__SPECS_REL__/AGENTS_SPEC.md` and `__SPECS_REL__/SDKWORK_WORKSPACE_SPEC.md`.
