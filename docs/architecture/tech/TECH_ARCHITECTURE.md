# sdkwork-scaffold Technical Architecture

Status: active
Owner: sdkwork-platform
Specs: SDKWORK_WORKSPACE_SPEC.md, AGENTS_SPEC.md, CODE_STYLE_SPEC.md

## 1. Purpose

Generate a standards-aligned SDKWork repository plus composable browser surface shells from one command.

## 2. Layers

```text
bin/sdkwork-scaffold.mjs   CLI and user-facing result
lib/arguments.mjs          validation and normalization
lib/generator.mjs          plan, variables, filesystem writes, post-generation automation
lib/template.mjs           safe template traversal and token rendering
lib/icon.mjs               deterministic PNG icon generation
lib/verify.mjs             local generated-repository contract checks
scaffold.config.mjs        template and surface registry
templates/                 authored template groups
```

## 3. Template Contract

- A template group is a directory under `templates/`.
- Every file is UTF-8 text except binary assets generated by code.
- Tokens use `__UPPER_SNAKE__` and must resolve from `createVariables` / `createSurfaceVariables`.
- Paths are relative, may not contain `..`, and are resolved inside the target root.
- A per-surface group is copied once per selected surface.
- Adding an architecture is a registry entry plus a template group; the CLI does not change.
- `--self-check` renders every template for every surface and fails on unknown tokens.

## 4. Safety

- A non-empty target is refused unless it carries `.sdkwork/scaffold.json`.
- `--force` is refused for an unrecognized target.
- Template traversal rejects symlinks and path escapes.
- No credentials, environment values, runtime state, or fabricated screenshots are generated.
- The scaffold icon is a deterministic authored PNG, explicitly marked for replacement.

## 5. Post-Generation

When `sdkwork-specs` is available:

1. `bootstrap-repository-docs.mjs` scaffolds missing Canon directories.
2. `bootstrap-app-assets.mjs` scaffolds the app-assets tree and capture config.
3. AGENTS managed-block sync tools add the canonical naming, destructive-operation, rollback, main-branch, and SDK-generation blocks.

Failures are reported and do not corrupt the generated source tree.

## 6. Verification

```bash
pnpm check
```

Covers argument validation, self-check, generation, overwrite safety, surface subsets, token resolution, and generated repository contracts.
