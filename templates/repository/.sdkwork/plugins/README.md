# Repository Plugins

Repository-local agent plugins live here, one package per plugin.

A plugin may register tools, commands, or hooks for this repository. Keep plugin credentials and local configuration under `.sdkwork/secrets/` or another ignored path; never commit them.

Follow `__SPECS_REL__/AGENTS_SPEC.md` and `__SPECS_REL__/SDKWORK_WORKSPACE_SPEC.md`.
