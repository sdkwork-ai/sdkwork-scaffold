# sdkwork-scaffold Workspace

Source-controlled development metadata for the scaffold repository. Not runtime state.

- `skills/` — repository-local agent skills.
- `plugins/` — repository-local agent plugins.
- Ignored local directories: `local/`, `tmp/`, `cache/`, `secrets/`, `manual-backups/`.

Follow `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`.
