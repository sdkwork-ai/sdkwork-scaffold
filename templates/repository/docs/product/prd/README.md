# Product PRD Directory

This directory owns the product Canon for `sdkwork-__APP_CODE__`.

## Fixed Entry

- [PRD.md](PRD.md) — required entry document. Keep the problem, users, goals, scope, and success metrics here.

## Splitting Rules

- Split large PRD content into sibling shards named `PRD-<kebab-topic>.md`.
- Every shard must be linked from `PRD.md`.
- Durable requirements use `REQ-*` documents under `docs/product/requirements/`.

See `__SPECS_REL__/DOCUMENTATION_SPEC.md` and `__SPECS_REL__/REQUIREMENTS_SPEC.md`.
