# App Assets

Governed application media for `sdkwork-__APP_CODE__`.

## Layout

- `media/` — catalog and store-facing media; never imported by application source.
- `media/store/` — store-specific derivatives.
- `resources/` — runtime or content resources owned by the application.
- `capture/` — capture configuration and evidence metadata.
- `source/` — optional editable design masters.

## Current State

The scaffold generates one deterministic geometric icon at `assets/media/icons/icon-1024.png` so the app manifest and asset contract are runnable from the first commit. It is a scaffold mark, not a finished brand asset: replace it with designed media before catalog or store publication. No screenshots, covers, or store derivatives are fabricated.

## Rules

- Do not commit personal data, live customer content, or unlicensed assets.
- Record rights and license basis for every photograph, illustration, font, and footage item.
- Follow `__SPECS_REL__/APP_ASSETS_SPEC.md` and `__SPECS_REL__/MEDIA_RESOURCE_SPEC.md`.
